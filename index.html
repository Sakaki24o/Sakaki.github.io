Python · AI · Accessibility
AI Voice
Assistant

A voice-activated desktop assistant built to empower visually impaired users to control their Windows PC entirely through natural speech. Inspired by my sister, who is partially blind — addressing the gap where screen readers are passive and commercial assistants like Alexa or Siri can only handle one command at a time.

PythonGoogle Gemini APISpeechRecognitionpyttsx3 TTScustomtkinterThreading

// Key Features

  • Voice-controlled app launcher — open Word, Excel, Chrome and more by speaking
  • Multi-command processing — handles simultaneous instructions, unlike Alexa or Siri
  • Google Gemini integration with multi-model fallback for reliable AI responses
  • Real-time text-to-speech feedback so users always know what the system is doing
  • Multithreaded architecture preventing UI freezes during live audio capture
  • Ambient noise calibration for accurate recognition in real environments
